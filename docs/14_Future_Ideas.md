## 10. Evaluation Questions

Before building an idea, ask:

- Does it reduce friction?
- Does it preserve evidence?
- Does it fit the architecture?
- Does it support real workflows?
- Is it better as a connector, module, or view?
- Does it create maintenance burden?
- Can it be built incrementally?
